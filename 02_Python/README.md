## Detalhamento dos Módulos
A jornada está organizada em **11 módulos**, cada um com foco em conceitos específicos:

### MÓDULO 1 - Primeiros Passos (A Base da Base)
**Objetivo:** Entrar no universo Python sem sustos
- `print()` - primeiro contato
- Comentários de código (padrão profissional)
- Interpretando mensagens de erro
- Variáveis - criação e regras de nomenclatura

### MÓDULO 2 - Tipos de Dados Básicos
**Objetivo:** Conhecer os tijolos fundamentais
- Números inteiros (`int`) e decimais (`float`)
- Textos (`str`) e f-strings (moderno)
- Booleanos (`bool`) e operadores lógicos
- `type()` para descobrir tipos
- Conversão entre tipos (`str()`, `int()`, `float()`)

### MÓDULO 3 - Entrada e Saída de Dados
**Objetivo:** Fazer programas que conversam com o usuário
- `input()` para receber dados
- `print()` avançado (formatação, separadores)
- f-strings na prática
- **Mini-projetos:** Calculadora simples, conversor de temperaturas

### MÓDULO 4 - Estruturas Condicionais
**Objetivo:** Dar inteligência aos programas
- `if` simples e indentação (CRUCIAL!)
- `if-else` e `if-elif-else`
- Operadores de comparação (`==`, `!=`, `>`, `<`)
- Operadores lógicos (`and`, `or`, `not`)
- Aninhamento de condicionais
- **Exercícios:** Jogos de adivinhação, classificações

### MÓDULO 5 - Estruturas de Repetição (Loops)
**Objetivo:** Automatizar tarefas repetitivas
- `while` - repetição baseada em condição
- `for` com `range()` - repetição com contador
- `break` e `continue` - controle de fluxo
- Loops aninhados
- **Exercícios:** Tabuada, somatórios, validações

### MÓDULO 6 - Estruturas de Dados I (Listas e Tuplas)
**Objetivo:** Trabalhar com coleções de dados
- Listas - criação, indexação, fatiamento
- Métodos de listas (`append()`, `remove()`, `pop()`, `sort()`)
- Iterando sobre listas com `for`
- Listas aninhadas (matrizes simples)
- Tuplas - imutabilidade e quando usar
- **Exercícios:** Médias, filtros, ordenações

### MÓDULO 7 - Estruturas de Dados II (Dicionários e Conjuntos)
**Objetivo:** Estruturas mais sofisticadas
- Dicionários - chave-valor, criação, acesso
- Métodos de dicionários (`keys()`, `values()`, `items()`, `get()`)
- Iterando sobre dicionários
- Conjuntos (`set`) - união, interseção, diferença
- Quando usar cada estrutura (decisão de design)
- **Exercícios:** Contagem de frequência, agrupamentos

### MÓDULO 8 - Funções
**Objetivo:** Organizar e reutilizar código
- Definindo funções com `def`
- Escopo de variáveis (local vs global)
- Parâmetros opcionais e valores padrão
- Retorno de múltiplos valores
- Documentação com docstrings (padrão profissional)
- **Exercícios:** Modularizando códigos anteriores

### MÓDULO 9 - Manipulação de Strings (Avançado)
**Objetivo:** Trabalhar com textos profissionalmente
- Métodos de string (`upper()`, `lower()`, `strip()`, `replace()`)
- Busca em strings (`find()`, `count()`, `in`)
- `split()` e `join()` - dividir e unir strings
- Formatação avançada (alinhamento, preenchimento)
- Expressões regulares (básico para o futuro)

### MÓDULO 10 - Arquivos
**Objetivo:** Ler e escrever arquivos (preparação para dados reais)
- Abrindo arquivos com `open()` e modos de abertura
- Lendo arquivos (`read()`, `readlines()`, `readline()`)
- Escrevendo arquivos (`write()`, `writelines()`)
- Gerenciadores de contexto (`with` - o jeito correto)
- Arquivos CSV (manual, sem pandas ainda)

### MÓDULO 11 - Introdução ao Pandas (A Ponte)
**Objetivo:** Conectar tudo que aprendemos com análise de dados
- Instalando pandas com `pip`
- Series - o "quase lista" do pandas
- DataFrames - o "quase tabela" do pandas
- Carregando dados reais com `read_csv()`
- Exploração inicial (`head()`, `info()`, `describe()`)
- Selecionando dados (colchetes, `loc`, `iloc`)
- Filtros - o `WHERE` do pandas
- Agrupamentos - o `GROUP BY` do pandas
