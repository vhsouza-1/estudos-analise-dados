## Detalhamento dos Arquivos

### Parte 1 - Print
- `print()` com aspas simples/duplas
- Parâmetros `sep` (separador) e `end` (final da linha)
- f-strings: `{variavel:.2f}`, alinhamento (`<` `>` `^`)
- Multiplicação de strings (`'=' * 20`)

### Parte 2 - Comentários
- Comentários de linha (`#`) e docstrings (`"""`)
- Comentar o **porquê**, não o óbvio
- `TODO:`, `FIXME:` para tarefas pendentes

### Parte 3 - Erros
- SyntaxError: esquecer de fechar aspas/parenteses
- NameError: variável não definida
- TypeError: operações com tipos incompatíveis
- ZeroDivisionError: divisão por zero

### Parte 4 - Variáveis
- Regras: snake_case, não começar com número, sem espaços
- Tipos: `int`, `float`, `str`, `bool`
- `type()` para descobrir o tipo
- Atribuição múltipla: `x, y = 10, 20`
- Troca de valores: `a, b = b, a`
