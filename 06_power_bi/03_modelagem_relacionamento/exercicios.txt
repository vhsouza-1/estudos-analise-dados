Exercício 7: Criar tabela Calendário (dimensão temporal)

No Power BI (não no Power Query):

Passos:

    Vá para a aba Relatório

    Página Inicial → Nova Tabela (ou Modelagem → Nova Tabela)

Fórmula DAX para criar calendário:
dax

Calendario = CALENDAR(DATE(2024,1,1), DATE(2024,12,31))

Adicionar colunas de navegação (no Power Query ou no DAX):
dax

Calendario = 
ADDCOLUMNS(
    CALENDAR(DATE(2024,1,1), DATE(2024,12,31)),
    "Ano", YEAR([Date]),
    "Mês", MONTH([Date]),
    "Mês Nome", FORMAT([Date], "MMM"),
    "Trimestre", QUARTER([Date]),
    "Dia da Semana", WEEKDAY([Date], 2),
    "Dia Nome", FORMAT([Date], "dddd")
)

Criar relacionamento:

    Arraste vendas.data até Calendario.Date

Exercício 9: Testar os filtros

Adicione segmentações (slicers):

    Segmentação de Produto: use produtos.produto

    Segmentação de Vendedor: use vendedores.vendedor

    Segmentação de Região: use vendedores.regiao

    Segmentação de Mês: use Calendario.Mês Nome

Teste as combinações:

    Selecione "Tênis" em produtos → todos os gráficos mostram apenas vendas de Tênis

    Selecione "Ana" em vendedores → apenas vendas da Ana

    Selecione ambas → venda de Tênis pela Ana

Pergunta: O que acontece quando você seleciona filtros de tabelas diferentes? Funciona?

R: Sim, tudo funciona perfeitamente, o pbi basicamente trata como se fosse tudo uma tabela só, igual com o Join/merge mesmo, na verdade é mais parecido com o Join porque você conserva as origens, no merge você junta tudo num df só. Adicionei também um cartão que mostra a soma de valor_total, isso complementa bastante a análise.
